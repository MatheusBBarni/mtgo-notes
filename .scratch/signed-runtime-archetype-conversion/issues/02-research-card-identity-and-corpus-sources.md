## Question

Which authoritative, stable sources can supply canonical MTG oracle identifiers and reproducible labeled deck corpora for Modern, Pauper, Pioneer, and Standard, and what licensing, attribution, redistribution, freshness, and rate-limit constraints would govern bundling that data in this repository?

## Comments

- Resolution: use Scryfall `oracle_id` values through frozen release tooling. Admit only project-authored, contributor-authorized, or explicitly licensed corpus records; otherwise keep the format unsupported/`Unclassified`.
