# ADR-003: Five brochure routes behind one layout

## Status

Accepted

## Date

2026-08-17

## Context

The PRD lists Home, Download, How it works, Live attach, and Privacy, and allows Home to fold some of them if the scroll stays short. Risk-sensitive visitors need bookmarkable live-attach and privacy copy. Home must stay one screen for the notes-first persona.

## Decision

Use **separate Astro routes** and one `BaseLayout`:

| Route | File | Owns |
|---|---|---|
| `/` | `src/pages/index.astro` | Pitch, three beats, tracker contrast, primary CTA |
| `/download` | `src/pages/download.astro` | Same CTA, version, requirements, empty state, secondary GitHub link |
| `/how-it-works` | `src/pages/how-it-works.astro` | Local notebook, confirm-before-persist, overlay, disclosure, public-result wording |
| `/live-attach` | `src/pages/live-attach.astro` | Optional attach, read-only boundary, required risk phrases |
| `/privacy` | `src/pages/privacy.astro` | No signup, no telemetry, local notes, export warning |

Shared chrome: `SiteHeader` (brand icon + wordmark + nav), `SiteFooter` (unofficial / not affiliated / GitHub), `DownloadCta` (Home + Download).

`DownloadCta` is a static `<a href="/download/windows">` upgraded by a small inline script that calls `/download/status`. No React island.

## Alternatives Considered

### Alternative 1: One long Home

- **Description**: Single `/` with in-page sections.
- **Pros**: Fastest to ship.
- **Cons**: Risk copy is not bookmarkable; Home stops being one screen.
- **Why rejected**: The cautious persona is explicit in the PRD.

### Alternative 2: Home + Download only

- **Description**: Other topics become Home sections.
- **Pros**: Fewer pages.
- **Cons**: `/live-attach` and `/privacy` disappear as URLs.
- **Why rejected**: Those pages are the risk and privacy contract.

## Consequences

### Positive

- Home stays short. Legal and attach copy have stable URLs.
- One layout enforces footer and icon on every page.

### Negative

- Five pages of copy to keep consistent. Shared phrases belong in `src/content/copy.ts`, not duplicated strings.

## Implementation Notes

- `trailingSlash: 'never'`.
- `/download?available=0` is the no-JS empty state for the Download page.
