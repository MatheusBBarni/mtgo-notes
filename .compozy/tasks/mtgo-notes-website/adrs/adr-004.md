# ADR-004: Ship Inter instead of Haas Grotesk

## Status

Accepted

## Date

2026-08-17

## Context

`DESIGN.md` specifies Haas Grotesk / Haas Groot Disp. Those faces are commercial. This repository does not contain a Haas license. The frozen tree already vendors Inter under the OFL.

`DESIGN.md` itself names Inter Display as the closest open-source substitute when Haas is unavailable.

## Decision

Self-host **Inter** (variable, via `@fontsource-variable/inter` or checked-in woff2). Keep `DESIGN.md` sizes, weights (400 display / 500 labels and buttons), tracking, line-height, colors, radii, and spacing.

Do not load fonts from Google Fonts or any other third-party font CDN (PRD forbids third-party tracker-class requests; a font CDN is an unnecessary third-party connection).

Do not embed Haas files unless a later ADR records a license and the files are added on purpose.

## Alternatives Considered

### Alternative 1: Embed Haas

- **Description**: Use the named faces exactly.
- **Pros**: Pixel-faithful to `DESIGN.md`.
- **Cons**: No license in-repo.
- **Why rejected**: Cannot ship an unlicensed commercial font.

### Alternative 2: System stack only

- **Description**: `system-ui` / Segoe UI, no webfont.
- **Pros**: Smallest payload.
- **Cons**: Weaker editorial match, especially on Windows.
- **Why rejected**: Inter is already the documented substitute and is OFL.

## Consequences

### Positive

- Legal to ship. Visual tokens besides the family name stay intact.

### Negative

- Headlines will not match Haas metrics exactly. Accept the `DESIGN.md` substitute note (slightly tighter line-height if needed).

### Risks

- Someone adds a Google Fonts `<link>` later. Copy/network tests must fail that.

## Implementation Notes

- Map `{typography.display-*}` and `{typography.title-*}` to Inter. Do not introduce a second family for V1 (skip the DESIGN.md pricing-only Inter Display dialect; this site has no pricing page).
